# Как школьник написал свой язык программирования: CodeX (черновик статьи)

Мне 16, я из Казахстана. Мне стало интересно, как языки работают внутри, — и я написал CodeX на Go: свой лексер, парсер и интерпретатор, ноль зависимостей. Рассказываю, что получилось и какие грабли собрал.

## Зачем, если есть Python

Python умеет всё, но у него 10 способов сделать одно действие. Новичку это мешает. Я хотел язык с одним очевидным путём: `x := 5`, `for s in scores`, `if hp > 0`. Читается как псевдокод, выполняется по-настоящему: игры, лог-анализаторы, HTTP-серверы.

## Лексер за вечер

Источник режется на токены, каждый знает строку и колонку. Поэтому ошибки точные: `Lexer error at 2:6`, а не «где-то там». Строки понимают `\n \t \r \e`, комментарии `//` сохраняются для форматтера.

## Парсер: прескан структур

Главная ловушка: `if hp > 0 {` — это условие с блоком, а `Boss{777, 1000}` — литерал структуры. Парсер сначала пресканит все `struct Name`, и только известные имена + `{` на той же строке считаются литералом. Приоритет операторов классический: `2 + 3 * 4` это `14`.

## Рантайм без сборщика мусора

Скоупы цепочкой: global → function → block. Когда скоуп умирает, его структуры освобождаются (в дебаге видно `[del]`). `return/break/continue` едут наверх через panic-сигналы, которые ловятся на нужном уровне. Ошибки — тоже panic со стеком `at fn`, а `try/catch` их перехватывает.

## Пакеты без реестра

Реестров не люблю. Пакет — любой публичный GitHub-репозиторий: `import "user/repo"`, версия после `@`, явный файл через `/`. Скачанные zip лежат в `~/.codex/pkgs`. Первые официальные пакеты живут в самом репозитории: `strutils`, `mathx`, `apix`, `csvx`. Каталог — `packages.json`, команды `codex list/search/info`.

## Что умеет сейчас

~86 функций: строки, массивы (`map/filter/reduce/find/any/all`), мапы, файлы, JSON, `http_get/http_post/http_listen`, каналы и `spawn/wait`, `assert()`-тесты через `codex test`, `codex fmt` + `fmt --check` для CI, REPL, установка одной командой.
